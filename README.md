# Study Together — Goals + Camera

This version keeps the shared goals and adds a working peer-to-peer camera call.

- Create a room and send the new room link.
- Shared goals are cumulative: one person's goal does not replace another person's goal.
- Camera uses WebRTC/PeerJS. Each person must allow camera access.
- Camera is video-only; the existing voice call remains separate.
- GitHub Pages HTTPS is required for browser camera permission.
